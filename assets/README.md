# Brand assets

The StadiaRef icon, logotype and graphics. The name and the mark are trademarks of Seguru Digital (see [NOTICE](../NOTICE)); use them to refer to StadiaRef, not for a fork or another product.

| File | What |
|---|---|
| `stadiaref-icon.svg` | The product icon: the white S mark on StadiaRef orange, round |
| `stadiaref-plugin-icon.svg` | The same mark, square, for the WordPress plugin |
| `stadiaref-logotype.svg` | The logotype for light backgrounds |
| `stadiaref-logotype-on-dark.svg` | The logotype for dark backgrounds |
| `stadiaref-logotype-mono.svg` | The logotype in one colour (`currentColor`) |
| `github-social-preview.png` | 1280 × 640, the repository's social preview |

The logotype is drawn from outlines of Barlow Bold (SIL Open Font License 1.1), so no font is needed to show it.

`src/` holds the HTML the PNGs are rendered from: `node scripts/render-graphics.mjs`.
