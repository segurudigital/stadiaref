# Brand assets

The StadiaRef icon, logotype and graphics. The name and the mark are trademarks of Seguru Digital (see [NOTICE](../NOTICE)); use them to refer to StadiaRef, not for a fork or another product.

| File | What |
|---|---|
| `stadiaref-icon.svg` | The product icon: the black S mark on Signal Lime `#A3E635`, round |
| `stadiaref-plugin-icon.svg` | The same mark, square, for the WordPress plugin |
| `stadiaref-logotype.svg` | The logotype for light backgrounds ("Ref" in Lime Ink `#3F6212`) |
| `stadiaref-logotype-on-dark.svg` | The logotype for dark backgrounds ("Ref" in Signal Lime) |
| `stadiaref-logotype-mono.svg` | The logotype in one colour (`currentColor`) |
| `github-social-preview.png` | 1280 × 640, the repository's social preview |
| `wordpress-org/icon-128x128.png`, `icon-256x256.png` | The WordPress.org plugin directory icon |
| `wordpress-org/banner-772x250.png`, `banner-1544x500.png` | The WordPress.org banner: dark navy `#0F172A` with lime accents |

The logotype is drawn from outlines of Barlow Bold (SIL Open Font License 1.1), so no font is needed to show it.

`src/` holds the HTML the PNGs are rendered from: `node scripts/render-graphics.mjs`.

The colour is Signal Lime `#A3E635` (Seguru Brand Handbook 4.12, 2026-10-09). Before 3.1.0 StadiaRef was orange `#EA580C`. The "by Seguru Digital" mark in the social preview is the parent mark, the white S on Primary Blue `#00C0F3`; it never takes the product colour.
