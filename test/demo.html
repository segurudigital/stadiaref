API

StadiaRef demo

An address for every part of the screen. This section has a data-ref attribute, so it always has a label. Press D to hide or show StadiaRef.

Features

Press L to cycle the labels through Off, Icons and Full. Click any label to copy its address. Press P and point at anything to see its address, or / to find one.

Testimonials (class converter)

This section has the CSS class dataref-home-03-testimonials but no data-ref attribute. With the class converter on, StadiaRef turns the class into data-ref="home-03-testimonials".

Offer (no address)

This section has no data-ref attribute and no dataref- class. With auto-address on, it gets a temporary address from the page slug and its position, shown with a dashed AUTO label.

Call to action

This section has its own data-ref. Auto-address never changes an authored address.
